# GitHub Pages Setup

This weather app is now ready to run on GitHub Pages!

## How to Enable GitHub Pages

1. Go to your repository: https://github.com/Siddheshh21/Weather-app
2. Click **Settings** → **Pages**
3. Under "Build and deployment" section:
   - **Source:** Select `Deploy from a branch`
   - **Branch:** Select `main` 
   - **Folder:** Select `/docs`
4. Click **Save**

GitHub Pages will be live at: `https://Siddheshh21.github.io/Weather-app/`
